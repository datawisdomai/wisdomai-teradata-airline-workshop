---
name: Airline technical answer validation
description: Use when validating an airline answer, troubleshooting SQL, or preparing a workshop demonstration.
---

1. Inspect selected sources and native grains.
2. Check date basis, coverage and filters.
3. Check joins, duplicate keys, row counts and fanout.
4. Recompute ratios from sums and snapshots at a single date.
5. Execute reference SQL and compare results using stated tolerances.
6. Record failures and corrections.
7. Keep holdout questions separate from reviewed training examples; do not mark unexecuted SQL as validated.
